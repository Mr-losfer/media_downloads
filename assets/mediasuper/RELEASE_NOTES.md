# 更新内容

## v2.5.9

**新增完整插件系统**：导航「文档」改为「插件」菜单，新增插件管理页与在线插件市场。

- 一个插件 = 一个文件夹 + `plugin.json`，Go 插件可含多个 `.go` 主要代码文件；公众号解析已纳入插件体系（内置，可配置 / 禁用 / 另存为副本）。
- 插件在 `config_schema` 里定义**用户可视化配置选项**，列表自动出现「配置」按钮，弹窗按 text / password / number / switch / select / textarea / url 渲染。
- 通过 `match.domains` / `url_patterns` / `path_prefixes` / `schemes` / `extensions` / `priority` 声明**发现哪一种域名提交下载时运行本插件**。
- 三种执行引擎：`declarative`（零编译、上传即用）、`go`（独立子进程 + stdin/stdout JSON 行协议）、`builtin`（内置）。
- 插件页支持本地上传 zip / 文件夹、在线市场（对接 Git 仓库 `marketplace.json`）、启停、配置、文件编辑、差量修改、编译、测试 / 调试、导出、复制、删除。
- 文档页新增最详细的**插件开发文档**，REST API 文档补齐全部接口与提交示例；MCP 工具从 11 个扩到 **36 个**（25 个插件开发能力）。

## v2.5.8

**新增防重复下载**：同一个视频链接不再重复下载，提交时直接拦截、不创建第二条任务。

- 提交任务只按**链接**判断重复：忽略 `#` 片段、统一协议与主机名大小写、去掉默认端口和路径末尾斜杠，`query` 里的签名参数保持原样；命中返回 `409` 并带 `duplicate` / `reason` / `task_id`。
- 「设置 → 下载」新增**标题防重**开关（默认关闭）：开启后相同标题也不再下载，空标题不参与判断。
- 失败 / 已取消的任务不拦截，可直接重新提交或用「重试」；想重新下载已完成的同一链接，先删除那条任务记录即可。
- 批量提交（公众号解析）里重复项统计为「跳过 N 个重复」，不会误报成失败，其余视频照常入队。
- REST / MCP 提交统一走同一套防重检查；本次重新打包 fpk，安装后显示新的 losfer Media 图标。

## v2.5.7

**新增插件化链接解析**：首页粘贴公众号文章先解析、再把视频直链作为下载对象，普通直链流程完全不变。

- 识别 `https://mp.weixin.qq.com/s/*` 后展示解析结果：标题 / 封面 / 作者 / 简介 / 发布时间 / 文章图片 / 正文摘要。
- 文章里的 `movie_down_url` 列成可勾选视频列表（默认全选、可全不选），批量提交为普通下载任务，**一般是 mp4 直链、无需 ffmpeg 合成**。
- 新增 `internal/parser` 插件框架（`Parser` 接口 / 注册表 / 统一 `Result`），后续增加解析站点只需实现并注册一行，**前端与下载引擎都不用改**。
- 新增 `GET /api/parsers` 与 `POST /api/parse`，文档页、README、架构文档补充接口与扩展说明。
- 解析服务空文章 / 业务失败 / 非 JSON / 超时均有明确中文提示；外部图片、正文与链接做安全过滤后再渲染。
- 解析服务地址可用环境变量 `MS_MP_PARSE_API` 换成自建服务；新增 10 项解析插件单测（mock 解析服务）。
